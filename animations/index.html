跑起来看（按钮、滑块能动）

在仓库根目录的 Claude 会话里说"打开 cs285 动画"即可（.claude/launch.json 里的 cs285-animations 配置）。自己在终端跑：

python3 -m http.server 8345 --directory cs285-deep-rl/notes/animations

然后浏览器打开 http://localhost:8345/l01-agent-environment.html。直接双击 html 也能打开。

新增或修改一个动画

  1. 页面引用 anim.css 和 anim.js（与 vla-deep-dive/notes/animations/ 同一套；讲义动画另外共用 rl-common.js（扫地机器人、网格世界）和 rl-walk.js（随机游走），数字和 solutions/chapter-code/rl_envs.py 一致），提供 reset(seed) 和 next()（返回 false 表示播完），用 setupPlayer({captureSeed, reset, next}, 毫秒) 挂上播放按钮。随机数一律用 rnd() / gauss()，录制结果可复现。
  2. 重新录 GIF（在本目录下执行）：

bash node ../../../tools/anim-capture/capture.mjs l01-agent-environment.html l01-agent-environment.gif 350
