先修：问题、回报与期望

R01 · 强化学习的交互循环是哪几步？轨迹怎么写？为什么第一个奖励是 \(R_1\) 不是 \(R_0\)？

来源：第 1 章 · 加入 2026-10-26 · 复习记录：

答案

智能体看到状态 \(S_t\) → 做动作 \(A_t\) → 环境给出奖励 \(R_{t+1}\) 和新状态 \(S_{t+1}\) → 循环。

轨迹：\(S_0, A_0, R_1, S_1, A_1, R_2, \dots\)（Sutton & Barto 式 3.1）

奖励是做完动作之后才拿到的，所以第 0 步动作的奖励记作 \(R_1\)。

口诀：看状态，做动作，拿奖励，再看新状态。

R02 · 强化学习和监督学习最大的区别是什么？智能体和环境的边界按什么划？

来源：第 1 章 · 加入 2026-11-13 · 复习记录：

答案
  • 监督学习给正确答案（标签）；强化学习只给分数（奖励），正确的做法要自己试出来，而且奖励可能来得很晚。
  • 边界规则（S&B L3698）：智能体不能随意改变的东西都算环境，包括机器人的电机、身体，以及奖励本身。不是按"身体"划的。

口诀：监督学习给答案，强化学习只给分；改不了的都是环境。

R03 · 回报 \(G_t\) 怎么定义？从哪个奖励开始加？\(G_T\) 是多少？

来源：第 2 章 · 加入 2026-11-13 · 复习记录：

答案

\(G_t = R_{t+1} + R_{t+2} + \cdots + R_T\)（式 3.7）：从第 t 步往后的奖励总和，起点是 \(R_{t+1}\)，已经拿到的不算。

最后一步之后没有奖励，所以 \(G_T = 0\)。

例：奖励 1, 0, 1, 0 → \(G_0 = 2\)，\(G_1 = 1\)，\(G_2 = 1\)，\(G_3 = 0\)。

R04 · 分幕任务和持续任务有什么区别？为什么奖励不应该奖励"中间步骤"？

来源：第 2 章 · 加入 2026-11-13 · 复习记录：

答案
  • 分幕任务（episodic）能切成一局一局，每局结束于终止状态；持续任务（continuing）没有终点，不打折的回报可能加到无穷大。
  • 奖励是告诉智能体要什么，不是怎么做（S&B L3970–L3971）。奖励中间步骤（比如下棋吃子），智能体会钻空子：拼命吃子却输掉整盘。
  • 迷宫每步 −1 = "越快出去越好"。

R05 · 折扣回报的公式是什么？γ = 0 和 γ = 1 分别意味着什么？

来源：第 3 章 · 加入 2026-11-13 · 复习记录：

答案

\(G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty}\gamma^k R_{t+k+1}\)（式 3.8），往后第 k 个奖励乘 \(\gamma^k\)。

  • γ = 0：近视，只看下一步；
  • γ = 1：不打折，就是第 2 章的回报；
  • γ 越接近 1 越有远见。

例：γ = 0.9，奖励 1, 0, 1 → \(G_0 = 1 + 0 + 0.81 = 1.81\)。

R06 · 回报的递推式是什么？每步奖励都是 +1 时折扣回报是多少？

来源：第 3 章 · 加入 2026-11-13 · 复习记录：

答案

\(G_t = R_{t+1} + \gamma G_{t+1}\)（式 3.9）：今天往后的总价值 = 明天到手的 + γ × 明天往后的总价值。从 \(G_T = 0\) 倒着推最省事。

每步 +1：\(\sum_{k=0}^{\infty}\gamma^k = \frac{1}{1-\gamma}\)（式 3.10）；γ = 0.9 时是 10，大致就是"看多远"。

推导：\(X - \gamma X = 1\)。

R07 · 期望怎么算？不知道概率时怎么估？条件期望里的竖线是什么意思？

来源：第 4 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(\mathbb{E}[X] = \sum_x x\Pr(X = x)\)：每个值乘它的概率再相加，就是按概率的加权平均（例：30% 出 10、70% 出 0 → 期望 3）；
  • 不知道概率：多试几次取平均，次数越多越接近期望（大数定律）；
  • \(\Pr(X \mid Y = y)\)、\(\mathbb{E}[X \mid Y = y]\)：竖线右边是已知条件，左边是要猜的结果；每个条件下概率加起来都是 1。

MDP、策略与价值

R08 · \(p(s', r \mid s, a)\) 怎么读？它满足什么条件？

来源：第 5 章 · 加入 2026-11-13 · 复习记录：

答案

"在状态 s、做了动作 a 的条件下，到达 s'、拿到奖励 r 的概率"（式 3.2），叫 MDP 的动力学（dynamics），把环境完全写清楚了。

条件：固定一组 (s, a)，所有 (s', r) 的概率加起来 = 1（式 3.3）。

例（扫地机器人）：\(p(\text{高电}, -3 \mid \text{低电}, \text{搜索}) = 0.3\)。

R09 · 马尔可夫性质是什么？从 p 怎么算 \(p(s' \mid s, a)\) 和 \(r(s, a)\)？

来源：第 5 章 · 加入 2026-11-13 · 复习记录：

答案
  • 马尔可夫性质：下一步只取决于现在的状态和动作，跟更早的历史无关；这是对状态的要求：状态要包含所有对未来有用的信息（下棋看整个棋盘）。
  • \(p(s' \mid s, a) = \sum_r p(s', r \mid s, a)\)（把奖励加掉，式 3.4）；
  • \(r(s, a) = \sum_r r\sum_{s'}p(s', r \mid s, a)\)（按概率平均奖励，式 3.5）。例：\(r(\text{低电}, \text{搜索}) = 0.7 \times 2 + 0.3 \times (-3) = 0.5\)。

R10 · 策略 \(\pi(a \mid s)\) 是什么？随机策略和确定性策略的区别？一步的平均奖励怎么算？

来源：第 6 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(\pi(a \mid s)\)：在状态 s 选动作 a 的概率，智能体的"行事手册"，每行加起来是 1；学习就是在改它（p 是环境的，改不了）。
  • 随机策略按概率掷骰子；确定性策略每个状态只选一个动作（概率 1）。
  • \(\mathbb{E}_\pi[R_{t+1} \mid S_t = s] = \sum_a\pi(a \mid s)\,r(s, a)\)：先按 π 选动作，再按 p 平均。例：高电 0.9 × 2 + 0.1 × 1 = 1.9。

R11 · \(v_\pi(s)\) 和 \(q_\pi(s, a)\) 的定义是什么？两者差在哪？

来源：第 7 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]\)（式 3.12）：从 s 出发、一直按 π 走，折扣回报的平均（状态的"房价"）；
  • \(q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]\)（式 3.13）：第一步固定做 a，之后按 π 走；
  • 价值和策略绑在一起；终止状态的价值永远是 0；不会算时可以"多跑几次取平均"（蒙特卡洛）。

R12 · v 和 q 之间的两个关系式是什么？

来源：第 7 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(v_\pi(s) = \sum_a\pi(a \mid s)\,q_\pi(s, a)\)：v 是 q 按策略的加权平均；
  • \(q_\pi(s, a) = \sum_{s', r}p(s', r \mid s, a)\,[r + \gamma v_\pi(s')]\)：q 是"这一步奖励 + γ × 下一个状态的 v"的平均。

例：\(q_\pi(\text{低电}, \text{充电}) = 0 + 0.9 \times 15.828 = 14.245\)。

R13 · 写出 Bellman 期望方程（式 3.14），并说出从里往外怎么读

来源：第 8 章 · 加入 2026-11-13 · 复习记录：

答案
\[v_\pi(s) = \sum_a\pi(a \mid s)\sum_{s', r}p(s', r \mid s, a)\,[r + \gamma v_\pi(s')]\]
  1. 方括号：某个具体结果之后的总价值；
  2. 按 p 平均：得到 \(q_\pi(s, a)\)；
  3. 按 π 平均：得到 \(v_\pi(s)\)。

来源：把 \(G_t = R_{t+1} + \gamma G_{t+1}\) 两边取期望。每个状态一个方程，n 个状态 n 个一次方程，知道 p 就能直接解：\(v = (I - \gamma P_\pi)^{-1}r_\pi\)。

R14 · 5×5 网格世界随机策略下，为什么 A 格价值 8.8 小于 +10、B 格 5.3 大于 +5？

来源：第 8 章 · 加入 2026-11-13 · 复习记录：

答案
  • A 格：拿 +10 后被传到最下一行的 A'，靠墙、随机乱走常撞墙扣分（A' 价值约 −1.3），所以 \(v(A) \approx 10 + 0.9 \times (-1.3) = 8.8\)；
  • B 格：拿 +5 后传到中间的 B'（价值约 0.4），不容易撞墙，后面还有点赚头，所以 5.3 > 5。

R15 · Bellman 最优方程（式 3.19、3.20）和期望方程比，哪一层变了、哪一层没变？

来源：第 9 章 · 加入 2026-11-13 · 复习记录：

答案
\[v_*(s) = \max_a\sum_{s', r}p(s', r \mid s, a)[r + \gamma v_*(s')]$$ $$q_*(s, a) = \sum_{s', r}p(s', r \mid s, a)[r + \gamma\max_{a'}q_*(s', a')]\]
  • 选动作那一层：从"按 π 平均"换成"取 max"（最优的智能体直接挑最好的）；
  • 环境那一层：不变，还是按 p 平均（环境把你送到哪你挑不了）。

R16 · 有了 \(v_*\) 或 \(q_*\)，怎么得到最优策略？扫地机器人的最优策略是什么？

来源：第 9 章 · 加入 2026-11-13 · 复习记录：

答案
  • 有 \(v_*\)：每个状态往前看一步，挑 \(\sum p[r + \gamma v_*(s')]\) 最大的动作（对 \(v_*\) 贪心就是最优，因为 \(v_*\) 已经包含了所有未来）；
  • 有 \(q_*\)：直接挑 \(q_*(s, a)\) 最大的动作，连 p 都不用知道；
  • 机器人：\(v_*(\text{高电}) = 16.949\)、\(v_*(\text{低电}) = 15.254\)；高电搜索、低电充电（低电时充电 15.254 > 等待 14.729 > 搜索 14.686）。

动态规划

R17 · 迭代策略评估（式 4.5）怎么做？4×4 网格第 2 轮挨着终点那格为什么是 −1.75？为什么会收敛？

来源：第 10 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(v_{k+1}(s) = \sum_a\pi(a \mid s)\sum_{s', r}p[r + \gamma v_k(s')]\)：把 Bellman 期望方程当更新规则，右边用旧值、左边写新值，从全 0 开始反复套；
  • −1.75：四个方向"−1 + 邻居第 1 轮的值"分别是 −2、−2、−2、−1（往终点那个），平均 −1.75；
  • 收敛：真价值是"不动点"，每轮误差至少缩成 γ 倍（压缩映射）；最终 0、−14、−20、−22 …

R18 · 策略改进怎么做？策略改进定理说了什么？

来源：第 11 章 · 加入 2026-11-13 · 复习记录：

答案
  • 每个状态挑 \(q_\pi(s, a)\) 最大的动作：\(\pi'(s) = \arg\max_a q_\pi(s, a)\)（式 4.9，对 \(v_\pi\) 贪心）；
  • 策略改进定理：若每个状态 \(q_\pi(s, \pi'(s)) \ge v_\pi(s)\)，则每个状态 \(v_{\pi'}(s) \ge v_\pi(s)\)，新策略处处不比原来差；
  • 只改一个状态时的判断：\(q_\pi(s, a) > v_\pi(s)\) 就换。

R19 · 策略迭代的流程是什么？为什么"改进后策略不变"就是最优？

来源：第 11 章 · 加入 2026-11-13 · 复习记录：

答案
  • 流程：评估 → 贪心改进 → 评估 → …（\(\pi_0 \to v_{\pi_0} \to \pi_1 \to \cdots \to \pi_*\)），策略不再变就停；
  • 不变说明每个状态的 π 已经在挑 q 最大的动作，于是 \(v_\pi\) 满足 Bellman 最优方程；最优方程只有一个解，所以 \(v_\pi = v_*\)；
  • 有限 MDP 的确定性策略有限多，每轮严格变好或停下，一定在有限轮内结束（4×4 网格 3 轮）。

R21 · 什么是广义策略迭代 GPI？DP 最大的局限是什么？

来源：第 12 章 · 加入 2026-11-13 · 复习记录：

答案
  • GPI：评估（让价值跟上策略）和改进（让策略对价值贪心）两个过程你推我拉，最后同时满足时就是 \(v_*\)、\(\pi_*\)；策略迭代、价值迭代、异步 DP 只是两者的"粒度"不同；书里说几乎所有 RL 方法都可以看成 GPI；
  • DP 的局限：必须知道环境的 p；状态太多时扫一遍都算不动（维度灾难）。

不知道 p：边试边学

R22 · 探索和利用是什么矛盾？ε-greedy 怎么选动作？为什么纯贪心会被困住？

来源：第 13 章 · 加入 2026-11-13 · 复习记录：

答案
  • 利用：选目前看起来最好的，眼前收益最大；探索：试看起来不怎么样的，可能发现更好的。一次只能做一样。
  • ε-greedy：以 1 − ε 的概率选估计最大的动作，以 ε 的概率随便选一个。
  • 纯贪心：开头运气好的那个一直被选，别的动作一次都没试过，永远不知道更好的存在（3 台老虎机实验：贪心只有 21% 选到最好的，ε = 0.1 有 89%）。

R23 · 增量更新的公式是什么？通用句式是什么？步长 \(\frac1n\) 和常数 α 有什么区别？

来源：第 13 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(Q_{n+1} = Q_n + \frac1n[R_n - Q_n]\)（式 2.3）：只需记住当前平均和次数；例 2、4、6、8 → 2、3、4、5；
  • 通用句式（式 2.4）：新估计 = 旧估计 + 步长 × (目标 − 旧估计)，贯穿全书（MC、TD、Q-learning 只是换了目标）；
  • \(\frac1n\) 就是真平均；常数 α（式 2.5）更看重最近的奖励，适合会变的环境，但会一直抖。

R24 · 蒙特卡洛 MC 怎么估价值？first-visit 是什么意思？MC 的毛病是什么？

来源：第 14 章 · 加入 2026-11-13 · 复习记录：

答案
  • 不需要 p：一局局玩，每经过一个状态就记下它之后的真实回报 G，取平均（倒着算回报最方便）；
  • first-visit：每局里每个状态只用第一次出现之后的回报；
  • 常数 α 版：\(V(S_t) \leftarrow V(S_t) + \alpha[G_t - V(S_t)]\)（式 6.1）；
  • 毛病：要等一局结束；整局随机、方差大；这局没走到的状态学不到。

R25 · TD(0) 的更新式和 TD 误差 δ 是什么？在随机游走里手算：V 全是 0.5，从 E 走出右边拿 +1，α = 0.1，V(E) 变成多少？

来源：第 15 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(V(S_t) \leftarrow V(S_t) + \alpha[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)]\)（式 6.2）；
  • \(\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\)：走一步后发现比预期好了多少；
  • E 走出去：终点价值 0，\(\delta = 1 + 0 - 0.5 = 0.5\)，\(V(E) = 0.5 + 0.1 \times 0.5 = 0.55\)。之后 D → E 时 D 也会跟着涨（好消息往前传）。

R26 · 什么是 bootstrapping？DP、MC、TD 各用不用采样、用不用 bootstrap？TD 和 MC 的偏差–方差各怎样？

来源：第 15 章 · 加入 2026-11-13 · 复习记录：

答案

bootstrapping（自举）：用自己的估计去更新自己的估计。

采样（不要 p） bootstrap
DP 否 是
MC 是 否
TD 是 是

MC 目标 \(G_t\) 无偏但方差大（整局随机）；TD 目标方差小（一步随机）但用了不准的估计，有偏。随机游走上 TD 学得更快。

R27 · SARSA 和 Q-learning 的更新式差在哪？用"−1 + 下一格 Q = [−5, −12, −4, −6]、下一步实际选 ↑（−5）"算两个目标

来源：第 16 章 · 加入 2026-11-13 · 复习记录：

答案
  • SARSA（式 6.7）：目标 \(R + \gamma Q(S', A')\)，用真正要做的下一个动作；
  • Q-learning（式 6.8）：目标 \(R + \gamma\max_a Q(S', a)\)，用下一格最好的动作（就是 Bellman 最优方程的样本）；
  • 例（γ = 1）：SARSA −1 + (−5) = −6；Q-learning −1 + (−4) = −5。

R28 · on-policy 和 off-policy 是什么意思？悬崖行走里两个算法为什么走出不同路线？

来源：第 16 章 · 加入 2026-11-13 · 复习记录：

答案
  • on-policy（SARSA）：学的就是正在执行的 ε-greedy 策略的价值；off-policy（Q-learning）：做的是 ε-greedy，学的是贪心策略的 \(q_*\)。
  • 悬崖：Q-learning 学最短路线、贴着悬崖走，但执行时 10% 乱走常掉下去（训练中每局约 −51）；SARSA 把"自己会乱走"算进价值，绕到上面走（约 −27）。ε 慢慢变 0 时两者都收敛到最优路线。
  • off-policy 的好处：能用旧数据、别人的数据（DQN 经验回放的基础）。

函数近似与深度价值方法

R29 · 导数是什么？梯度下降怎么走？\((w - 3)^2\) 从 w = 0、步长 0.1 出发，前两步是多少？

来源：第 17 章 · 加入 2026-11-13 · 复习记录：

答案
  • 导数 = 斜率：自变量往右挪一点，函数变了多少（\(x^2\) 的导数是 2x，在 3 处是 6）；多个参数各求一个排成向量就是梯度 ∇；
  • 梯度下降：\(w \leftarrow w - \text{步长} \times \frac{df}{dw}\)，朝下坡走一小步；
  • 例：导数 2(w − 3)。w = 0 → 0 − 0.1 × (−6) = 0.6 → 0.6 − 0.1 × (−4.8) = 1.08 → … → 3。

R30 · 函数近似的 SGD 更新式（式 9.7）是什么？线性函数时梯度是什么？什么叫半梯度？

来源：第 17 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(\mathbf w \leftarrow \mathbf w + \alpha[U_t - \hat v(S_t, \mathbf w)]\nabla\hat v(S_t, \mathbf w)\)：往"目标 − 估计"的方向挪，乘上每个参数对估计的影响；
  • 线性 \(\hat v = \mathbf w \cdot \mathbf x(s)\) 时，\(\nabla\hat v = \mathbf x(s)\)（特征本身）；
  • 目标 \(U_t = G_t\) 是梯度 MC；\(U_t = R + \gamma\hat v(S', \mathbf w)\) 是半梯度 TD：目标里也有 \(\mathbf w\)，但不对它求导，快但可能不稳。
  • 好处：调 \(\mathbf w\) 会让相似状态一起变（泛化）。

R31 · DQN 的 loss 怎么写？回合结束时 y 是什么？

来源：第 18 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(y = r + \gamma\max_{a'}Q(s', a'; \theta^-)\)（用目标网络算，当常数不求导）；
  • \(\text{loss} = (y - Q(s, a; \theta))^2\)，一批取平均，对 θ 做梯度下降（本质是回归）；
  • 结束时没有下一步：\(y = r\)（代码里乘 \((1 - \text{done})\)）。
  • 例：r = 0，γ = 0.9，\(Q(s', \cdot; \theta^-) = [0.5, 0.8]\) → y = 0.72。

R32 · 经验回放和目标网络各解决什么问题？为什么 Q-learning 能用经验回放？

来源：第 18 章 · 加入 2026-11-13 · 复习记录：

答案
  • 经验回放：把 (s, a, r, s', done) 存进缓冲区、训练时随机抽一批 → 打乱前后相关的数据、每条经历反复用；能用旧数据是因为 Q-learning 是 off-policy（学 \(q_*\) 不要求数据来自当前策略）；
  • 目标网络：目标 y 里有 θ，改 θ 目标就晃（追自己的影子）；复制一份 \(\theta^-\) 专门算 y，隔一阵才对齐（或 Polyak 软更新），让回归目标在一段时间内固定。

R33 · 什么是最大化偏差？Double DQN 的目标怎么写？

来源：第 19 章 · 加入 2026-11-13 · 复习记录：

答案
  • 最大化偏差：估计有噪声时，max 会挑到"运气最好"的那个，\(\mathbb{E}[\max_a Q(a)] \ge \max_a q(a)\)（10 个真值 0 的动作，估计的 max 平均 0.69）；Q-learning 目标里有 max，偏差会一步步往前传；
  • 修法：一组估计挑动作、另一组打分（Double learning，偏差降到 0）；
  • Double DQN：\(y = r + \gamma\,Q(s', \arg\max_{a'}Q(s', a'; \theta); \theta^-)\)，主网络挑、目标网络打分。

策略梯度

R34 · 策略梯度定理怎么写？"方便的恒等式"是什么？它起了什么作用？

来源：第 20 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(\nabla J(\theta) = \mathbb{E}_{\pi_\theta}[\sum_t G_t\,\nabla\log\pi_\theta(A_t \mid S_t)]\)：回报大的动作被推得更可能；
  • 方便的恒等式：\(\nabla\pi = \pi\nabla\log\pi\)（来自 log 的导数是 1/x）；
  • 作用：把 \(\sum_a q(a)\nabla\pi(a)\) 写成 \(\sum_a\pi(a)[q(a)\nabla\log\pi(a)]\)，梯度变成了期望，可以用样本估；不需要知道 p，也不需要对奖励求导。

R35 · softmax 策略的 \(\nabla\log\pi(a)\) 是什么？REINFORCE 的更新式？θ = [0, 0]、抽到机器 1、G = 2、α = 0.1 时 θ 变成多少？

来源：第 20 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(\nabla_\theta\log\pi_\theta(a) = \text{one-hot}(a) - \pi_\theta\)；
  • REINFORCE（式 13.8）：\(\theta \leftarrow \theta + \alpha G_t\nabla\log\pi_\theta(A_t \mid S_t)\)；
  • 例：\(\nabla\log\pi(1) = [0, 1] - [0.5, 0.5] = [-0.5, 0.5]\)；θ = [0, 0] + 0.1 × 2 × [−0.5, 0.5] = [−0.1, 0.1]，π(机器 1) 从 0.5 涨到约 0.55。
  • 缺点：要等终局、方差大。

R36 · 为什么要减 baseline？为什么减了不会把梯度弄错？

来源：第 21 章 · 加入 2026-11-13 · 复习记录：

答案
  • 用 \((G - b)\) 代替 G：只看"比平常好多少"，好的推高、差的压低；奖励都在 10 左右时，方差从 27.85 降到 0.25；
  • 无偏：\(\mathbb{E}[b\nabla\log\pi] = b\sum_a\pi\nabla\log\pi = b\sum_a\nabla\pi = b\nabla\sum_a\pi = b\nabla 1 = 0\)；只要 b 不随动作变（可以随状态变）。

R37 · reward-to-go 是什么？奖励 [1, 0, 2, 0] 的 reward-to-go 是多少？它为什么也不改变期望？

来源：第 21 章 · 加入 2026-11-13 · 复习记录：

答案
  • 时刻 t 只乘它之后的奖励之和 \(\hat Q_t = \sum_{t' \ge t}r_{t'}\)（就是 \(G_t\)）：一个动作只为它之后的结果负责（因果性）；
  • [1, 0, 2, 0] → [3, 2, 2, 0]；
  • 过去的奖励和现在的动作无关，那部分乘 \(\nabla\log\pi\) 平均下来是 0，所以去掉它只降方差、不改期望。

R38 · 优势函数是什么？为什么 TD 误差能当优势用？actor-critic 的两个更新是什么？

来源：第 22 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)\)：这个动作比平常好多少，按策略平均为 0；
  • \(\delta = r + \gamma\hat V(s') - \hat V(s)\)：用一个样本代替 Q，评委准时 \(\mathbb{E}[\delta \mid s, a] = A(s, a)\)；
  • 评委：\(\phi \leftarrow \phi + \alpha_\phi\delta\nabla\hat V_\phi(s)\)；演员：\(\theta \leftarrow \theta + \alpha_\theta\delta\nabla\log\pi_\theta(a \mid s)\)。不用等终局、方差小，但评委不准时有偏。

R39 · GAE 的公式是什么？λ = 0 和 λ = 1 分别等于什么？

来源：第 22 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(\hat A_t = \sum_{l \ge 0}(\gamma\lambda)^l\delta_{t+l}\)，倒着算 \(\hat A_t = \delta_t + \gamma\lambda\hat A_{t+1}\)；
  • λ = 0：\(\hat A_t = \delta_t\)（一步 TD，方差小、有偏）；λ = 1：\(G_t - \hat V(s_t)\)（MC 优势，无偏、方差大）；常用 0.95。
  • 例：奖励 [0, 0, 1]，\(\hat V\) = [0.5, 0.6, 0.8]，γ = 0.9 → δ = [0.04, 0.12, 0.2]；λ = 1 时 [0.31, 0.3, 0.2]。

R40 · 重要性采样的公式是什么？PPO 里的比率 \(r_t(\theta)\) 是什么？为什么每次只能改一点？

来源：第 23 章 · 加入 2026-11-13 · 复习记录：

答案
  • \(\mathbb{E}_{p_{\text{新}}}[f] = \mathbb{E}_{p_{\text{旧}}}[\frac{p_{\text{新}}}{p_{\text{旧}}}f]\)：用旧数据估新策略的平均，每个样本乘权重（例：旧各 0.5、新 0.8/0.2，样本 1 和 0 → 0.8）；
  • \(r_t(\theta) = \pi_\theta(a_t \mid s_t) / \pi_{\theta_{old}}(a_t \mid s_t)\)，替代目标 \(\mathbb{E}[r_t\hat A_t]\)；
  • 只能改一点：比率离 1 太远时方差爆炸；策略变了状态分布也会变，只有新旧策略差得不多时才可以忽略（信任区域，TRPO 用 KL ≤ δ）。

R41 · PPO 的剪裁目标（式 7）是什么？A > 0 和 A < 0 时分别什么时候梯度为 0？

来源：第 23 章 · 加入 2026-11-13 · 复习记录：

答案
\[L^{\text{CLIP}} = \mathbb{E}[\min(r_t\hat A_t,\ \text{clip}(r_t, 1-\varepsilon, 1+\varepsilon)\hat A_t)]\]
  • A > 0：r 涨过 1 + ε（如 1.2）后目标变平、梯度 0（好动作最多涨到旧的 1.2 倍）；
  • A < 0：r 低于 1 − ε（如 0.8）后梯度 0（坏动作最多压到 0.8 倍）；
  • min 保证只在"改对了但过头"时剪；改错方向（A > 0 但 r = 0.5）时不剪，照样有梯度拉回来。

R42 · GRPO 的优势怎么算？和 PPO 有什么区别？参考模型的 KL 正则是防什么的？

来源：第 24 章 · 加入 2026-11-13 · 复习记录：

答案
  • 同一道题生成 G 个回答，\(\hat A_i = \frac{r_i - \text{mean}(r)}{\text{std}(r)}\)，分给回答里每个词；[1, 0, 0, 1] → [1, −1, −1, 1]；全对或全错时全是 0，没有学习信号；
  • 区别：PPO 要训练评委网络 + GAE 逐词打分；GRPO 不要评委，用组内平均当 baseline（第 21 章的想法），剪裁照用；
  • 参考模型 KL：\(\text{奖励} - \beta D_{KL}(\pi_\theta\|\pi_{ref})\)，防止整个训练过程中离最初的模型太远、钻奖励模型的空子（PPO 剪裁防的是"每一步"改太多）。
