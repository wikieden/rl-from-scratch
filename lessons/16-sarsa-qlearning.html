第 16 章 · SARSA 与 Q-learning：用 TD 学 q，学会怎么做

本章回答：TD 只学会了"评估"，怎么用它来找最好的动作？SARSA 和 Q-learning 只差一个字，结果为什么会走出两条完全不同的路线？on-policy 和 off-policy 是什么意思？
讲解日期：2026-11-13 · 上一章：第 15 章 时序差分 TD · 下一章：第 17 章 函数近似与梯度下降
对应原文：Sutton & Barto §6.4 Sarsa（L9365–L9513，式 6.7，算法框 L9438）、§6.5 Q-learning（L9514–L9653，式 6.8，算法框 L9537，例 6.6 悬崖行走 L9563，图 6.4）
本章缩写：SARSA = State, Action, Reward, State, Action（状态 / 动作 / 奖励 / 下一状态 / 下一动作，一次更新用到的五样东西）；Q-learning：学 Q（动作价值 q）的方法；on-policy：同策略（学的和做的是同一份策略）；off-policy：异策略（学的和做的不是同一份）。全部缩写见 附录 · 缩写与术语表

讲解

第一步：从学 V 到学 Q：不知道 p 时，挑动作要靠 q（2026-11-13）

问题：第 15 章的 TD 学会了 \(V(s)\)。可是知道了 \(V\)，怎么挑动作？第 9 章说过：有 \(v_*\) 时要"往前看一步"，算 \(\sum p\,[r + \gamma v(s')]\)，这需要 p。

办法（第 9 章第三步末尾）：直接学动作价值 \(Q(s, a)\)。有了 Q，挑动作只要看哪个 Q 最大，不需要 p。

用 TD 学 Q：把第 15 章公式里的 \(V(S_t)\) 换成 \(Q(S_t, A_t)\)，"下一状态的估计"换成"下一个状态–动作的估计"：

\[Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\,\big[\,R_{t+1} + \gamma\, \underbrace{(\text{下一步的 Q})}_{?} - Q(S_t, A_t)\,\big]\]

"下一步的 Q"取哪个，就分出了本章的两个算法。

整体流程是 GPI（第 12 章）：边学 Q（评估），边用 Q 来选动作（改进）。选动作用 ε-greedy（第 13 章），保证每个动作都会被试到。

一句话：不知道 p 时，学 Q 而不是学 V，挑动作看 Q 最大；用 TD 更新 Q，"下一步的 Q"取哪个分出两个算法。

第二步：SARSA：用真正要做的下一个动作（2026-11-13）

SARSA（式 6.7，L9405–L9410）：下一步的 Q 用实际要做的下一个动作 \(A_{t+1}\)：

\[Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\,\big[\,R_{t+1} + \gamma\, Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t)\,\big]\]

名字的来历（L9413–L9416）：一次更新用到 \(S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1}\) 五样，首字母连起来就是 S-A-R-S-A。

流程（算法框 L9438）：

  1. 在 S 按 ε-greedy 选好动作 A；
  2. 做 A，看到 R 和 S'；
  3. 在 S' 按 ε-greedy 选好下一个动作 A'（这一步真的会去做）；
  4. 用 \(Q(S', A')\) 更新 \(Q(S, A)\)；
  5. S ← S'，A ← A'，回到 2。

on-policy（同策略）：SARSA 学的 Q，是"按 ε-greedy 这份策略行事"的 Q：包括它偶尔会乱走那 10%。学的和做的是同一份策略。

一句话：SARSA 的目标用实际要做的下一个动作 \(Q(S', A')\)；学的是自己正在执行的 ε-greedy 策略的价值（on-policy）。

第三步：Q-learning：用下一格最好的动作（2026-11-13）

Q-learning（式 6.8，L9520–L9524；Watkins 1989）：下一步的 Q 用下一个状态里最大的那个，不管自己实际会做什么：

\[Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha\,\big[\,R_{t+1} + \gamma\, \max_a Q(S_{t+1}, a) - Q(S_t, A_t)\,\big]\]

认出来了吗：方括号里的目标就是第 9 章 Bellman 最优方程（式 3.20）右边，只是把"按 p 平均"换成了"一个真实样本"。所以 Q-learning 直接学的是最优的 \(q_*\)（"directly approximates q*"，L9527–L9528）。

off-policy（异策略）：做动作时还是 ε-greedy（会乱走），但学的是"以后一直挑最好的"那份贪心策略的 Q。做的和学的不是同一份策略。

手算对比：在格子 (3, 0)，往上走，奖励 −1，到了 (2, 0)。(2, 0) 四个动作当前的 Q（编的）：

动作 ↑ ↓ → ←
Q((2,0), ·) −5 −12 −4 −6

假设 ε-greedy 在 (2, 0) 这次掷骰子掷到了"乱走"，选了 ↑。γ = 1：

  • SARSA 目标 = \(-1 + Q((2,0), \uparrow) = -1 + (-5) = -6\)（用真正要做的 ↑）；
  • Q-learning 目标 = \(-1 + \max = -1 + (-4) = -5\)（用最好的 →）。

同一步经历，两个算法得出不同的目标。

一句话：Q-learning 的目标用下一格最大的 Q，等于在采样解 Bellman 最优方程；学的是贪心策略的 \(q_*\)，做的却是 ε-greedy（off-policy）。

第四步：悬崖行走：一个走安全路，一个贴着悬崖走（2026-11-13）

算法 学到的路线 训练中最后 100 局平均每局奖励
SARSA 绕到上面走（第 0–2 行），离悬崖远 −27.2
Q-learning 贴着悬崖走（第 2 行） −51.3

和书上图 6.4 一样：SARSA 每局大约 −25，Q-learning 大约 −50。

为什么会这样：

  • Q-learning 学的是"以后都挑最好的"：如果永远不乱走，贴着悬崖走是最短路线（13 步，−13），这确实是最优的。所以它学到了这条路；
  • 但它实际执行时有 10% 会乱走：贴着悬崖时，乱走一步向下就掉下去 −100。所以训练中它的实际得分反而更低；
  • SARSA 学的是"包括我会乱走"的价值：它把"在悬崖边乱走会掉下去"算进了 Q 里，于是学会离悬崖远一点，绕远路，多走几步但很少掉下去。

类比：新手司机和老司机。 老司机（Q-learning）知道最短路线是贴着护栏开；新手（SARSA）知道自己手会抖，选择离护栏远一点的车道。如果新手手会抖（ε 不为 0），新手的选择实际上更安全。

两点补充：

  1. 如果让 ε 慢慢变到 0（不再乱走），两个算法都会收敛到贴着悬崖的最优路线（L9641–L9642）；
  2. Q-learning 的 off-policy 性质很有用：它可以从别人的经验、旧的经验里学最优策略，这正是第 18 章 DQN 用"经验回放"的基础。

一句话：悬崖上 SARSA 把自己的乱走算进去、绕远路，训练得分高；Q-learning 学最短路线、贴着悬崖，乱走时常掉下去；ε → 0 时两者一样。

数学原理

  • SARSA 收敛：在"每个状态–动作都无限次访问、ε 逐渐变到 0"（GLIE，Greedy in the Limit with Infinite Exploration：极限时贪心、探索无限次）的条件下，以概率 1 收敛到 \(q_*\)（L9423–L9428）。
  • Q-learning 收敛：只要每个状态–动作被无限次更新、步长满足第 13 章的条件，就收敛到 \(q_*\)，与行为策略无关（L9527–L9530）；这就是 off-policy 的含义。
  • Q-learning 目标 = 最优方程的样本：\(\mathbb{E}[R + \gamma\max_a q_*(S', a) \mid s, a] = q_*(s, a)\)（式 3.20）。
  • max 带来的偏差：\(\max_a Q(S', a)\) 在 Q 有噪声时会偏高，这是第 19 章"过估计"的来源。

公式清单

公式 意思
\(Q(S,A) \leftarrow Q(S,A) + \alpha[R + \gamma Q(S', A') - Q(S,A)]\) SARSA（式 6.7）
\(Q(S,A) \leftarrow Q(S,A) + \alpha[R + \gamma\max_a Q(S', a) - Q(S,A)]\) Q-learning（式 6.8）
以 1 − ε 选 \(\arg\max_a Q(S, a)\)，以 ε 随机 两者共用的行为策略

if method == "sarsa":
    target = r + (0 if done else gamma * Q[ns][na])     # 真正要做的下一个动作
else:
    target = r + (0 if done else gamma * Q[ns].max())   # 下一格最好的动作
Q[s][a] += alpha * (target - Q[s][a])

代码里才看得到的：eps_greedy 在并列时用 rng.choice(np.flatnonzero(q == q.max())) 随机挑（第 13 章附录提到的问题）。一开始 Q 全是 0，如果总挑编号最小的"↑"，智能体会在起点一直往上撞墙，学得很慢。
